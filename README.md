## Ce que je construis

**Ça Mange Où**, application interne chez Bouygues Telecom, web et mobile, utilisée chaque jour par une vingtaine de personnes.
Backend .NET en cinq couches (Domain, Application, Infrastructure, Persistence, WebApi) en DDD et architecture hexagonale, front React Native et Expo, authentification OAuth 2.0 PKCE avec Microsoft Entra ID, tests xUnit, qualité suivie sous SonarQube, déploiement Docker sur Azure.

**Annuaire groupe**, frontend React complet branché sur une API ASP.NET existante.
Recherche full-text avec Meilisearch, filtres et tri multicritères, fiche collaborateur, organigramme de toute l’entreprise, responsive, CI/CD Azure DevOps.

**Supervision chez Axima Concept**, application web Angular 12, PrimeNG et Java.
Nouvelles fonctionnalités, maintenance évolutive et corrective, maquettes Figma, au plus près des utilisateurs.

**Dywiki’s**, base de données de films en PHP 8.1, MySQL et JavaScript, alimentée par l’API TMDB.

## Architecture et méthode

Je structure le code pour qu’il survive au prototype : Clean Architecture, Domain-Driven Design, architecture hexagonale et principes SOLID.
Les règles métier sont testées, la dette technique est un choix assumé et documenté, sujet de mon mémoire de fin d’études sur l’industrialisation logicielle.
Je travaille en agile, en itérations courtes, en partant toujours du besoin réel des utilisateurs.

<br>

## IA générative

J’utilise l’IA pour livrer plus vite sans baisser l’exigence.

- **Développement assisté** avec Claude Code et Codex : génération de tests, refactoring, débogage, revue de code et documentation, avec une relecture humaine systématique.
- **Context engineering** : conventions de projet dans un CLAUDE.md pour que l’agent code comme l’équipe.
- **Systèmes d’agents** : LLM, multi-agents, harness engineering (outils, contexte, garde-fous, évaluation), MCP, RAG et tool calling.

<br>

## Algorithmie

Recherche et tri : recherche binaire, quick sort, merge sort.<br>
Graphes : parcours en profondeur (DFS), en largeur (BFS) et A*.
